## 👨‍💻 Quelques mots sur moi

J'ai commencé à développer par curiosité, puis j'ai continué par passion. Aujourd'hui, je consolide mes acquis au sein d'une **formation CDA** pour transformer cette expérience autodidacte en compétences professionnelles solides.

Ce qui me motive ? **Comprendre comment les choses fonctionnent, pas seulement les faire fonctionner.** De l'animation d'un personnage dans un Canvas à la circulation des données entre React, une API Express et PostgreSQL, j'aime relier les différentes pièces d'une application.

Je privilégie les projets concrets, les problèmes à résoudre et une progression continue. Mon GitHub reflète ce parcours : des applications ambitieuses, des projets collaboratifs, mais aussi des prototypes et des exercices qui témoignent de mon apprentissage.

## 🚀 Projets à découvrir

### 📦 Zesteo — Application web de gestion de livraisons

![Projet en évolution](https://img.shields.io/badge/Statut-En%20%C3%A9volution-2563EB?style=flat-square)
![Full Stack](https://img.shields.io/badge/Full--stack-React%20%7C%20Node.js%20%7C%20PostgreSQL-334155?style=flat-square)

**Mon projet personnel le plus structurant.** Une application web autour de la livraison et des prestations associées, qui me permet de travailler sur un véritable ensemble fonctionnel : catalogue de produits, variantes et options, panier, agences et logique métier.

Au-delà de l'interface, je m'intéresse particulièrement à la **modélisation des données**, aux échanges front-end/back-end, à la structuration du code et à la cohérence des règles métier.

**Stack :** React, Vite, Node.js, Express, PostgreSQL.

### 🎮 Flappy Dimensions — Jeu d'arcade en JavaScript

![Projet collaboratif](https://img.shields.io/badge/Projet-Collaboratif-7C3AED?style=flat-square)
![En développement](https://img.shields.io/badge/Statut-En%20d%C3%A9veloppement-2563EB?style=flat-square)

Un jeu d'arcade 2D développé **en binôme avec Thomas (Tosbas)**, inspiré du principe de Flappy Bird, mais revisité dans un univers fantastique avec un chevalier équipé d'un jetpack.

Ce projet est notre terrain d'expérimentation pour la **boucle de jeu**, les animations par spritesheets, les déplacements dépendants du temps, la physique, les collisions et la génération d'obstacles. **Objectif actuel : un premier niveau entièrement jouable.**

**Stack :** JavaScript natif, Canvas 2D, HTML, CSS, Vite, Git/GitHub.

[![Code GitHub](https://img.shields.io/badge/D%C3%A9couvrir_le_projet-GitHub-181717?style=flat-square&logo=github)](https://github.com/DevAurelien/Flappy)
